# UX phase, step 1: the game screen

The owner's order (5 Oct 2026): UI ("Nocą", live), then UX of the existing screens after the
canvas page "Flow aplikacji" (https://claude.ai/artifact/As2G6VoRzAPeEkLxmbC8Kx), then new
features. Each part goes to `master` once the branch's Check run is green.

Mockups: P40 (who scored, portrait), P41 (who scored, landscape), P42 (rod: the whole table, 8
rods), P43 (figure), P45/P46 (finish, landscape/portrait), P49 (turn the phone).

## Decisions

- No data or rules change: the goal detail stays a device setting (`fl.goalDetail`: position,
  rod, figure), the table's turn stays `fl.rotation` (quarter turns).
- Quarter turns keep their meaning on a phone lying flat: 0 and 2 show the portrait layout
  (seen from the blue or the red side), 1 and 3 the landscape layout turned by CSS a quarter
  either way, so it works with the rotation lock on. A landscape viewport (phone held sideways,
  tablet, desktop) always shows the landscape layout upright; turning there flips the sides.
- Rod and figure need the whole table, so they only work in the landscape layout; in portrait
  the screen asks to turn the phone (P49), with "record only who scored" as the way out.
- One DOM for both layouts where possible (header, board, table, bar), placed by CSS grid; the
  far team's cells and name plates are turned to face them (P41).

## Parts (all three live on 5 Oct 2026)

1. Portrait "who scored" (P40) and the finish card (P46): header with back, turn, detail,
   series/rules and clock, pause, menu; the score board with team names; whole cells tap for a
   goal; "Last" bar with the yellow undo; pause overlay with resume, leave for later, remove;
   finish card with the score, Elo preview, how it went, "Next" with an LED countdown, undo.
2. Landscape layout (P41, P45): side panel (icons, board with clock, last, undo, swaps), quarter
   turns 1/3 turn the whole screen by CSS in a portrait viewport.
3. The whole table for rod and figure (P42, P43, P49): rods in table order with figures,
   handles, name plates, a hit zone per rod or figure, "Own goal…" toggle in the side panel;
   the per-cell goal pad goes away.

End-to-end scenarios in `e2e/tests/game.spec.ts` follow each part (texts from `pl.json`).
